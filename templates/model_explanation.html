Model Explanation

Understanding the BiLSTM with Attention Mechanism for Insider Threat Detection

How the Model Works

This system uses a Bidirectional Long Short-Term Memory (BiLSTM) neural network with an attention mechanism to detect potential insider threats. Here's how it works:

  1. Data Processing: User activity logs are transformed into sequential data where each time window contains a set of engineered features.
  2. BiLSTM Network: Processes the sequence in both forward and backward directions to capture temporal patterns in user behavior.
  3. Attention Mechanism: Assigns weights to different parts of the sequence, highlighting which activities are most suspicious.
  4. Classification: Outputs a risk score indicating the likelihood of the user being an insider threat.

The attention mechanism is key to this system as it not only improves detection accuracy but also provides explainability by showing which activities contributed most to the detection.

BiLSTM with Attention Architecture
The Attention Mechanism

Attention mechanisms allow the model to focus on the most relevant parts of an input sequence when making predictions. In our insider threat detection system:

  • Purpose: Identifies which activities in a user's history are most suspicious.
  • How it works: Each timestep (activity window) gets an "attention weight" indicating its importance.
  • Explainability: Provides a clear explanation of why a user was flagged by showing which activities raised suspicion.
  • Visualization: Represented as a heatmap where darker colors indicate higher attention weights.
The attention weights are normalized to sum to 1, making it easy to interpret them as the relative importance of each timestep.
Features Used by the Model

The model analyzes various features extracted from user activity logs:

Feature Description
Activity Counts Number of logons, emails, file accesses, etc., in a time window
After-hours Activity Activities occurring outside normal business hours
Weekend Activity Activities occurring on weekends
External Email Ratio Proportion of emails sent to external domains
Large File Transfers Occurrences of large file downloads or transfers
Sensitive File Access Access to confidential or restricted files
USB Connects Frequency of USB storage device connections
Job Site Visits Visits to job search websites
Unusual Logon Types Remote logons during off-hours or from unusual locations

These features are normalized across all users and fed into the model as a sequential time series.

Model Performance

The BiLSTM with attention model provides several advantages over traditional methods:

Key Benefits
  • Temporal Understanding: Captures patterns across time
  • Bidirectional Context: Considers past and future activities
  • Attention-Based Explanation: Shows which activities matter most
  • Reduced False Positives: More accurate than threshold-based methods
Performance Metrics
Metric Value Description
Accuracy 92% Overall correctness of predictions
Precision 85% Accuracy of positive predictions
Recall 78% Ability to find all positive cases
F1 Score 81% Balance between precision and recall
